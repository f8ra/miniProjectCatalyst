# miniProjectCatalyst

Kopi Tuku Desa
Website company profile untuk Kopi Tuku Desa. Website ini satu halaman (single page) yang memperkenalkan kedai, menampilkan daftar menu yang bisa difilter, dan menyediakan informasi serta form untuk menghubungi kedai.

Latar Belakang dan Tujuan
Project ini dibuat sebagai mini project kelompok untuk berlatih membangun website statis dengan HTML, CSS, dan JavaScript, serta bekerja sama memakai Git dan GitHub (branch, issue, commit, dan pull request).

Fitur dan Section
- Navbar: Navigasi tetap di atas, menu hamburger di layar kecil, bayangan saat halaman digulir, dan link yang menyala sesuai section yang sedang dilihat
- Beranda (Hero):	Judul, deskripsi singkat, tombol "Lihat Menu" dan "Kunjungi Kami", serta ilustrasi cangkir kopi dari CSS dengan animasi uap
- Tentang Kami: Cerita kedai, tiga statistik singkat, serta kartu Visi dan Misi Menu Kami	10 menu dalam 3 kategori (Kopi, Non-Kopi, Makanan) dengan tombol filter dan harga berformat Rupiah
- Hubungi Kami:	Alamat (tertaut ke Google Maps), jam buka, telepon dan WhatsApp, email, serta form kontak dengan validasi
- Footer,	Slogan kedai, navigasi cepat, link media sosial, dan tahun hak cipta yang otomatis

Teknologi yang Digunakan
HTML5 untuk struktur halaman
CSS3 (Flexbox, Grid, CSS variables, media queries, animasi @keyframes)
JavaScript (vanilla, tanpa framework) untuk render dan filter menu, navbar mobile, IntersectionObserver, dan validasi form
Google Fonts: Bricolage Grotesque dan Figtree
Git dan GitHub untuk version control dan kolaborasi

Cara Menjalankan Secara Lokal
1. Clone repository: git clone https://github.com/f8ra/miniProjectCatalyst.git
2. Download Extension Live Server (VS Code), klik kanan index.html, lalu pilih Open with Live Server
